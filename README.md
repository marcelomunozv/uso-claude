# usage-band

Mod para Claude Code que muestra tres anillos sobre el cuadro donde escribes:

- **Verde**: porcentaje de contexto usado.
- **Naranja**: porcentaje de la ventana de 5 horas, con el tiempo que falta para el reinicio.
- **Azul**: porcentaje de la semana (7 días), con el tiempo que falta para el reinicio.

## Instalación

En una terminal de Claude Code:

```
/plugin install usage-band --marketplace marcelomunozv/uso-claude
```

Desde una shell:

```
claude plugin install usage-band --marketplace marcelomunozv/uso-claude
```

En la app de escritorio, donde `/plugin` no funciona: pulsa **+** junto al cuadro de escritura, luego **Plugins**, **Add marketplace** con `marcelomunozv/uso-claude`, y después **Add plugin**.
